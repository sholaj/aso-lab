# ASO + KRO Practical Learning Lab (Claude Agent Blueprint)

This document defines a structured, hands-on learning path for setting up an Azure Service Operator (ASO) lab in Azure using a personal Azure subscription. It is written for orchestration by Claude agents to assist learners in building muscle memory with ASO v2 and KRO.
---

## 🎯 **Learning Objectives**

* Understand the *core concepts* of Azure Service Operator v2 (ASO v2).
* Learn how ASO uses **CRDs**, **Reconciler Patterns**, **API versions**, and **ownership semantics**.
* Practise building Azure resources using **KRO (Kubernetes Resource Orchestrator)** templates.
* Deploy real Azure services (AKV, Storage, Log Analytics, AKS) using declarative YAML.
* Build muscle memory for GitOps workflows using Flux/Argo + ASO.
* Develop a reusable internal pattern for UBS UK8s future GitOps migration.

---

## 🧱 **Prerequisites**

* Azure subscription with Owner or Contributor role
* Kubernetes cluster (AKS or k3d/kind)
* kubectl, helm, az CLI, Git installed
* ASO v2 installed in the cluster
* KRO installed in the cluster

---

## 🧪 **Lab Roadmap (Hands-on Tasks)**

Use this roadmap with Claude to generate YAML, scripts, and explanations.

### **Phase 1 — Install the Tools (ASO + KRO)**

1. Create a resource group for the lab.
2. Deploy a small AKS cluster (1-node, cheapest SKU).
3. Install ASO v2 using Helm.
4. Install KRO.
5. Validate ASO CRDs.
6. Deploy a first trivial ASO resource.

**Outcome:** Kubernetes is now an Azure control-plane.

---

### **Phase 2 — Understand ASO Core Mechanics**

1. Inspect CRDs installed by ASO (Resource groups, KeyVault, Storage, Monitor…)
2. Understand how API versions map to Azure REST API
3. Use `kubectl explain` to explore schemas
4. Watch reconcile loops and events
5. Delete and recreate a resource to see lifecycle flow

**Outcome:** You understand how ASO maps Kubernetes → Azure.

---

### **Phase 3 — Build Foundational Azure Resources via ASO**

Deploy the following using native ASO CRDs:

* Resource Group
* Key Vault (with policies)
* Storage Account
* Log Analytics Workspace
* Container Registry

**Outcome:** You build simple Azure infra entirely through CRDs.

---

### **Phase 4 — Introduce KRO for Templating**

Convert the above individual ASO resources into **KRO templates**:

* A base KRO template for a Resource Group
* A KRO template for Key Vault
* A multi-resource composition (RG + KV + Storage)

**Outcome:** You understand templating & composition.

---

### **Phase 5 — Deploy AKS Using ASO + KRO**

1. Create a KRO template for AKS clusters.
2. Include add-ons (CSI, Defender, OIDC, LAW).
3. Add NodePool definitions.
4. Practise scaling through editing the YAML.

**Outcome:** You replicate the UBS UK8s deployment pattern in a simplified sandbox.

---

### **Phase 6 — GitOps Integration (Flux or Argo)**

1. Set up Flux/Argo on your lab cluster.
2. Push ASO/KRO manifests into Git.
3. Observe the GitOps reconciliation.
4. Introduce drift and watch Flux reconcile.

**Outcome:** End-to-end GitOps infra-as-Kubernetes.
